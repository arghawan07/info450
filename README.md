# Lesson 5: GitHub, JSON, Python Requests, and GitHub Pages

## Purpose
The purpose of this lesson is to practice storing structured JSON data on GitHub, retrieving it dynamically using Python, analyzing dictionary and list data structures in Google Colab, and publishing a project website using GitHub Pages.

## Work Completed
- **Data Storage:** Uploaded `worldcup.json` to the `lesson5/` directory in GitHub.
- **Data Retrieval:** Retrieved the dataset in Python using the `requests` library and the file's raw GitHub URL.
- **Data Exploration:** Analyzed data structures using `type()`, `.keys()`, and list indexing (`[-1]`) to extract details for the final World Cup match.
- **Documentation & Publishing:** Saved the Colab notebook (`lesson5.ipynb`) to GitHub and configured GitHub Pages to publish the project site.
